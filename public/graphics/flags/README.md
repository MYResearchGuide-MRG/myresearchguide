# Location flags

Small PNG flags from https://flagcdn.com, the same flag source used by the
previous globe component. Stored locally so the interactive globe does not
depend on third-party image requests. Flags are decorative next to location
names. Countries represented: Malaysia, Singapore, Australia, China, France,
United Kingdom, Germany, United States and Canada.

Canada, China and Germany were added in the 2026-11-02 researcher-directory
audit. Source URLs: https://flagcdn.com/w40/ca.png,
https://flagcdn.com/w40/cn.png, https://flagcdn.com/w40/de.png.

# Handbook walkthroughs

Four silent, ten-second MP4 tours made from the public MYResearchGuide Notion
handbook on 2 November 2026. These are captured page excerpts with a smooth
vertical pan, not a live Notion embed. The content, photos and illustrations
shown inside the videos are the actual handbook pages.

- `start`: https://myresearchguide.notion.site/Getting-Started-f8c78996497043858ae0ea4d2518b423
- `topic`: https://myresearchguide.notion.site/Finding-your-Research-Topic-326894103627804392cdd36924fe3bd3
- `write`: https://myresearchguide.notion.site/Writing-Your-Proposal-37e89410362780179830f3f940cff8e8
- `people`: https://myresearchguide.notion.site/Conversations-with-Researchers-626e8350aed144c79b9d621bd5980ead

Each WebP is the matching first-frame poster. MP4s are H.264, 760 × 560,
30 fps, without audio, with fast-start metadata. Only the selected video is
loaded once the section enters the viewport. Playback starts when the video itself
is visible and pauses offscreen or in a hidden tab; reduced-motion visitors see
the poster. An independent poster image remains visible until playback starts.
Normal autoplay has no controls; if the browser blocks playback (for example,
iPhone Low Power Mode), a Play preview button allows a user-initiated retry.

Refresh these recordings if the corresponding Notion chapters change.
The earlier `gif2.mp4`, `gif5.mp4` and `HandbookPreview.tsx` remain intact.

# Transparent affiliation logos

Derived from the existing PNG assets in the parent folder. The original files
are retained. Exterior matte residue and Meta's baked-in black background were
removed, then transparent padding was trimmed and the images reduced to a
maximum of 240 pixels per side for the smaller homepage strip.

Keep the original colours and preserve interior crest details. These marks
identify researchers' affiliations; they do not imply institutional endorsement.

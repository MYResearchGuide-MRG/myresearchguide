# Geist

`Geist-latin.woff2` is the same Google Fonts Geist Latin variable font already
downloaded by Next.js for this site's redesigned sections (weights 400 and 500).
It is bundled locally for the contact page so builds do not depend on a new
Google Fonts request. The font is licensed under the SIL Open Font License;
see `OFL.txt`, sourced from the official Google Fonts repository:
https://github.com/google/fonts/tree/main/ofl/geist
